# パラメータ

宣言にパラメータを付けることで、構造を抽象化できます。

## 基本

パラメータは名前の直後に `[...]` で書きます。

```
cat[C: *] = {
    x: C → C
    m: x x → x
    a: m x; m → x m; m
}
```

`cat` は 0-cell `C` をパラメータとして受け取るモジュールです。

## インスタンス化

パラメータを渡してインスタンスを作ります。

```
u: *
c = cat[u]

// c.x, c.m, c.a が使える
result = c.a
```

## 複数パラメータ

```
Hom[X: *, Y: *] = X → Y
```

## セルのパラメータ

型だけでなくセルもパラメータにできます。

```
rep2[x: C → C, f: x → x] = f; f
```

`rep2` は 1-cell `x` と 2-cell `f: x → x` を受け取り、`f` を2回合成した `f; f` を返します。

## 型エイリアス

パラメータ付き alias は型エイリアスとして使えます。

```
Endo[X: *] = X → X

f: Endo[u]   // u → u と同じ
```
