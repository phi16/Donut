# 合成

セルを繋ぎ合わせて高次のセルを構築します。

## 0次合成（並列）

スペースで区切ると **0次合成**（並列配置）になります。

```
u: *
x: u → u
y: u → u

// x と y を並べる: u u → u u
xy = x y
```

`x y` は `x` と `y` を横に並べた 1-cell です。source は `u u`、target も `u u` です。

## 1次合成（逐次）

`;` で区切ると **1次合成**（逐次結合）になります。

```
u: *
x: u → u
m: x x → x

// x を2つ並べてから m で合流: u u → u
xm = x x; m
```

1次合成では、左の target と右の source が一致する必要があります。

## 2次合成

`;;` で区切ると **2次合成** になります。3-cell 以上で使います。

```
a: m x; m → x m; m

// 2次合成の例
result =
    a x; m ;;
    x m x; a
```

## グルーピング

括弧 `()` で合成の優先順位を制御できます。

```
f: (x m; m) x → x m x; m x
```
