# 合成

セルを繋ぎ合わせて高次のセルを構築します。

## 0次合成（並列）

スペースで区切ると **0次合成**（並列配置）になります。

```
u: *
x: u → u
y: u → u

xy = x y    // u → u u → u u → u
```

`x y` は `x` と `y` を横に並べた 1-cell です。

## 1次合成（逐次）

`;` で区切ると **1次合成** になります。左の target と右の source が一致する必要があります。

```
u: *
x: u → u
μ: x x → x

xm = x x; μ    // u u → u
```

## 2次合成

`;;` で区切ると **2次合成** になります。3-cell 以上で使います。

```
α: μ x; μ → x μ; μ

result =
    α x; μ ;;
    x μ x; α
```

## 優先順位

高次の合成ほど結合が弱くなります:

1. スペース（0次）— 最も強い
2. `;`（1次）
3. `;;`（2次）— 最も弱い

`a b; c d ;; e f; g` は `((a b); (c d)) ;; ((e f); g)` と解釈されます。

括弧 `()` で優先順位を制御できます。
