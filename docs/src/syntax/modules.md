# モジュール

`{ }` でモジュールを定義できます。モジュール内の宣言はドット記法でアクセスします。

## 基本

```
cat = {
    u: *
    x: u → u
    m: x x → x
}

// モジュールのメンバーにアクセス
f: cat.u → cat.u
```

## ネスト

モジュールはネストできます。

```
a = {
    b = {
        u: *
        x: u → u
    }
    y: b.u → b.u
}

// a.b.x でアクセス
f: a.b.x a.b.x → a.b.x
```

## with 節

モジュールの後に `with { }` で追加の宣言ができます。with 節の中ではモジュール内の名前が直接使えます。

```
cat = {
    u: *
    x: u → u
} with {
    m: x x → x
}

// cat.m も定義される
```

## where 節

`where { }` でローカルな補助定義を書けます。

```
cat = {
    u: *
    x: u → u
    m: x x → x
} where {
    helper = x x; m
}
```

## `+=` によるメンバー追加

既存のモジュールや宣言にメンバーを追加できます。

```
f32: C → C

f32 += {
    lit[n: rat]: C → f32
    add: f32 f32 → f32
    neg: f32 → f32
}

// f32.lit[1], f32.add 等が使える
```

`+=` の右辺は `{ }` モジュールです。追加されたメンバーは元の名前のドット記法でアクセスできます。これは sys ライブラリの内部で、型にメソッドを追加するために使われています。
