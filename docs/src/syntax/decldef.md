# 定義

`:=` を使うと、宣言と定義を同時に行えます。

## 基本

```
x: * := y
```

これは以下と同等です:

- `x: *` を宣言する（新しいセルとして）
- `x.def: x ~ y` を自動生成する（`x` と `y` の equivalence）
- ランタイムで `x` を評価する際、`y` を代わりに評価する

## 型推論

型を省略すると、右辺から推論されます。

```
lit := sys.f32.lit
```

## 用途

定義は「新しい名前を付けつつ、実際の計算は既存の定義に委譲する」パターンで使います。定義として宣言されたセルは、図式上では独立したセルとして表示されますが、評価時には右辺の値として計算されます。
