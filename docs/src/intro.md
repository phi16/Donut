# Donut とは

Donut は **高次元セル** を合成してプログラムを組み立てる言語です。

通常のプログラミング言語が「値」と「関数」を扱うのに対し、Donut では **セル** を宣言して繋ぎ合わせます。セルには次元があり、次元ごとに異なる役割を持ちます:

| 次元 | セル | 意味 | 例 |
|------|------|-----|----|
| 0-cell | 点 | 環境・コンテキスト | `C: *` |
| 1-cell | 辺 | 型 | `Int: C → C` |
| 2-cell | 面 | 演算・プログラム | `add: Int Int → Int` |
| 3-cell | 立体 | 等式・書き換え | `comm: add → swap; add` |

次元は上に開いており、4-cell、5-cell... と続きます。

## 基本的な考え方

Donut の核にあるのは以下の3つの操作です。

- **宣言**: プリミティブなセルを置く。型は source と target の指定で決まる
- **合成**: セルをスペース（並列）や `;`（逐次）で繋ぐ。境界が一致すれば合成できる
- **型検査**: 合成の整合性（隣り合うセルの境界が一致するか）を自動で検証する

## 何ができる？

**抽象構造の記述**: モノイドなどの代数的構造を宣言し、結合律の証明（pentagon identity）のような高次の coherence 条件も表現できます。

**具体的な計算**: `import "sys"` でプリミティブ型（`f32`, `bool` 等）を読み込み、2-cell の合成だけで Mandelbrot 集合の描画のようなプログラムを書けます。

**Functor によるコンパイル**: `~>` で抽象的な環境と具体的な環境の間のマッピングを定義できます。プリミティブの対応だけ書けば、合成セルは自動的に変換されます。

## 最初の例

```
u: *
x: u → u
m: x x → x
```

これは以下を宣言しています:

- `u` は **0-cell**（環境）
- `x` は `u` 上の **1-cell**（型）
- `m` は `x x` から `x` への **2-cell**（二項演算）

`m` の型 `x x → x` は、1-cell `x` を2つ並べたもの（直積）を受け取り、1-cell `x` を返す 2-cell を意味します。これだけで「モノイド的な構造」の骨格が記述できています。

ここからさらに結合律を表す 3-cell を宣言すれば:

```
a: m x; m → x m; m
```

`m(m(a,b), c) = m(a, m(b,c))` という結合律の「証拠」が 3-cell として現れます。
